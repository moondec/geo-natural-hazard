## Idea of tele-detection 😄 HOW EO SATELLITES WORK
EO satellites can be divided into two types based on how they capture imagery; **passive** and **active**.
[IMG Kursy/prezentacje/ApplicationHazards_GEO/pliki/ezmaker.png]
<style>

<aside class="notes"><blockquote>
<h3 id="passive-eo-satellites">PASSIVE EO SATELLITES</h3>
</blockquote>
<p>Passive satellites detect radiation reflected off the Earth’s surface, such as visible light and infrared. In general, passive satellites are not able to work through clouds.</p>
<p>Approximate max resolution: 50cm</p>
<blockquote>
<h3 id="active-eo-satellites">ACTIVE EO SATELLITES</h3>
</blockquote>
<p>Active satellites transmit energy towards the Earth and measure the returned signal which provides information about the Earth’s surface. In general, active satellites can see through cloud.</p>
<p>Approximate max resolution: 25cm</p>
</aside>

## What next? Surface Classifier! _ML_ GEE machine learning
-   **Supervised Classification:** One ML technique for classifying land is to use ground truth examples to teach a model to differentiate between classes. Earth Engine's built-in [supervised classifiers](https://developers.google.com/earth-engine/guides/earth-engine/guides/classification) support this process.
-   **Unsupervised Classification:** In unsupervised classification, no ground truth examples are provided to the training algorithm. Instead, the algorithm divides the available data into clusters based on inherent differences. Earth Engine's [unsupervised classifiers](https://developers.google.com/earth-engine/guides/earth-engine/guides/clustering) are particularly useful when no ground truth data exists, when you do not know the final number of classes or when you want to do quick experimentation.
-   **Regression:** Whereas a classification model attempts to bucket each input into a discrete class, a regression model attempts to predict a continuous variable for each input. For example, a regression model could predict water quality, percent forest cover, percent cloud cover or crop yield. For more information, please refer to the [Linear Regression section of ee.Reducers](https://developers.google.com/earth-engine/guides/earth-engine/guides/reducers_regression).

## Decision Tree ➡️ Random forest
1. We need so called _**training set**_, and we pick random K points
1. ­Build the decision tree associated to K data points
1. ­Choose the number Ntree of trees we want to build and repeat STEP 1 & 2
1. ­For a new data point, make each one of Ntrees predict the category to which the data points belongs, and assign the new data point to the category that wins the major vote.
