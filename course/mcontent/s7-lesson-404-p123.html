Lab 7 (11.01, 4 h) takes Earth Engine out of the Code Editor. On this page you open a Google Colab notebook, authenticate Earth Engine with your Cloud project and learn how the same notebook can run R cells. At the end you have a working ee.Initialize() – the prerequisite for everything that follows.

Code for this lab

Python scripts, the Colab capstone template, the QGIS console scripts and the optional rgee scripts are on GitHub: moondec/geo-natural-hazard › examples (README explains how to open them in Colab).

Before you start

  • A Google account with Earth Engine access and the Cloud project id you registered in lab 1 (how to get access).
  • Google Colab notebook with a Python 3 kernel – free Jupyter in the browser, nothing to install; notebooks are saved to your Drive.
  • Google Colab notebook with a predefined R kernel.
  • Reference: Earth Engine Python quickstart.

Steps

  1. Create a notebook. Open the Python 3 Colab link above. Cells are either code (Shift+Enter runs them) or text (Markdown) – the report writes itself.
  2. Authenticate and initialise Earth Engine once per session with your Cloud project: 
    import ee, geemap
ee.Authenticate()                          # opens a browser window, sign in
ee.Initialize(project='your-project-id')   # the project from lab 1
print(ee.String('Hello from Earth Engine').getInfo())
  3. Check it works. The last line must print the string. If ee.Initialize complains about the project, copy the id exactly from the Cloud console (lab 1), not the project name.
  4. Optional: R inside the Python kernel. Load the rpy2 extension: 
    %load_ext rpy2.ipython
    Then use %%R as a cell magic at the very beginning of a cell if you want all its syntax executed in R: 
    %%R
a<-seq(1,10)
set.seed(1313) #for reproducible results
b<-runif(10)*a
#plot(b~a)
df<-data.frame('x'=a,'y'=b)
ggplot(df,aes(x,y))+theme_bw() + geom_point() + geom_smooth(method='lm')
  5. Line magic. Use %R to execute a single line in R; this is how you copy an R variable to Python: 
    # py_df - python variable
# df - R variable
py_df=%R df
print(py_df)

If rpy2 throws an error

Current Colab ships a working rpy2, so %load_ext rpy2.ipython normally works out of the box. As a last resort, reinstall the library and load the extension again:

!pip install -U rpy2
%load_ext rpy2.ipython

You are done when

ee.Initialize(project=...) runs without an error in a fresh Colab session. Do this at home before lab 7 (11.01) – two minutes at home save twenty in the lab. Press Next for the Colab exercise.
