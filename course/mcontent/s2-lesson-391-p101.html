Step 6: compute the area inside aoi covered by live, green vegetation. You add an NDVI band to every image, take the median, cut the median into classes and sum the pixel area of each class. At the end the Console prints the area per class – the template for your homework.

Before you start

Continue in the script from the previous page: the cloud-masked collection s2MaskedCS from step 5 (or s2Filtered from step 4 if you skipped the mask) and the geometry aoi must already exist. Use a buffer of a few kilometres (e.g. poi.buffer(5000)) so that the classes are visible.

1. Add NDVI and take the median

// ---- Step 6, cell 1: Add NDVI to every image and take the median ----
// Function: add an NDVI band to one image. normalizedDifference(A, B) = (A - B) / (A + B)
var addNDVI = function(image) {
  return image.addBands(image.normalizedDifference(['B8', 'B4']).rename('NDVI'));
};

// map() runs the function on every image of the (cloud-masked) collection
var s2ndvi = s2MaskedCS.map(addNDVI);

// Keep only the NDVI band, then reduce the time series to one image (median of each pixel)
var ndviCollection = s2ndvi.select(['NDVI']);
var ndviMedian = ndviCollection.median();
// ---- end of Step 6, cell 1 ----

2. Manual classification

We create a separate layer for each class, and then a code is assigned to each class. The NDVI boundaries below are examples from Lecture 2 – in your homework you must justify your own with Inspector values and the literature:

  • "water": NDVI ≤ 0 → code 1
  • "bare": 0 < NDVI ≤ 0.2 → code 2
  • "shrub": 0.2 < NDVI ≤ 0.4 → code 3
  • "green": NDVI > 0.4 → code 4

For the exercise only

This solution is not efficient – it is here to show how comparisons work. Do not use it in real calculations; use the threshold version in part 4.

// ---- Step 6, cell 2: Manual classification: one 0/1 band per class (exercise only) ----
// Manual classification: one 0/1 band per class, multiplied by the class code.
// Each comparison (lte, gt, and) gives 1 where the condition holds and 0 elsewhere.
var water      = ndviMedian.lte(0.0).rename('Water').multiply(1);                            // code 1
var bare       = ndviMedian.gt(0.0).and(ndviMedian.lte(0.2)).rename('Bare').multiply(2);    // code 2
var shrub      = ndviMedian.gt(0.2).and(ndviMedian.lte(0.4)).rename('Shrub').multiply(3);   // code 3
var vegetation = ndviMedian.gt(0.4).rename('Green').multiply(4);                            // code 4
// print(water);   // uncomment to inspect one of the class bands in the Console
// ---- end of Step 6, cell 2 ----

Now we can add the new bands to the image:

// ---- Step 6, cell 3: Stack the four class bands onto the NDVI image ----
// One image with five bands: NDVI, Water, Bare, Shrub, Green (addBands accepts a list)
var ndviWithClasses = ndviMedian.addBands([water, bare, shrub, vegetation]);
// Which bands does an image have? bandNames() lists them in the Console:
// print(ndviWithClasses.bandNames());        // ["NDVI", "Water", "Bare", "Shrub", "Green"]
// For a collection ask the first image: print(s2MaskedCS.first().bandNames());
// ---- end of Step 6, cell 3 ----

3. Compute the area

Finally compute the area (try changing "Green" to "Bare" or "Shrub"):

// ---- Step 6, cell 4: Area of one class (Green) with a grouped sum ----
// Area of the Green class: band 0 = pixel area in m2, band 1 = the class band (0 or 4);
// the grouped sum adds the pixel areas separately for each value of band 1
var greenAreaGroups = ee.Image.pixelArea().addBands(ndviWithClasses.select('Green'))
  .reduceRegion({
    reducer: ee.Reducer.sum().group({
      groupField: 1,
      groupName: 'code',
    }),
    geometry: aoi,
    scale: 10,  // Sentinel-2 native resolution, in metres
    maxPixels: 1e10
  }).get('groups');

// A list of two dictionaries: {code: 0, sum: m2 outside Green}, {code: 4, sum: m2 of Green}
print(greenAreaGroups);
// ---- end of Step 6, cell 4 ----

scale: 10, not scale: 1

Why not use scale: 1 ("sample the geometry at 1 m intervals"). Sentinel-2 pixels are 10 m; scale: 1 forces a hundred times more samples, ends with the error Too many pixels in the region or gives an over-smoothed answer. The scale must match the data: 10 for Sentinel-2, 30 for Landsat (see Lecture 2, "From classes to hectares").

4. Let's make it better – thresholds

The same four classes in one line: count how many thresholds each pixel exceeds and add 1, so the codes are again 1–4. This is the version to use in the homework – change the list of thresholds, nothing else:

// ---- Step 6, cell 5: Better: all four classes from three thresholds in one line ----
var thresholds = ee.Image([0, 0.2, 0.4]);   // class boundaries as a 3-band constant image
// gt() compares NDVI with each threshold (three 0/1 bands); the sum counts how many are exceeded;
// + 1 turns 0..3 into the codes 1..4 of the manual version
var classified = ndviMedian.gt(thresholds).reduce(ee.Reducer.sum()).add(1).toInt();
print(classified, 'Classified');

// Define new visualization parameters
// for the classification: the values range from 1 to 4, one for each class
var classifiedParams = {min: 1, max: 4, palette: ['blue', 'burlywood', 'yellowgreen', 'darkgreen']};
Map.addLayer(classified.clip(aoi), classifiedParams, 'Classified');
// ---- end of Step 6, cell 5 ----

// ---- Step 6, cell 6: Area of every class with the grouped sum ----
// The same grouped sum as above, now over the single class band (codes 1-4)
var areaPerClass = ee.Image.pixelArea().addBands(classified)
  .reduceRegion({
    reducer: ee.Reducer.sum().group({
      groupField: 1,
      groupName: 'code',
    }),
    geometry: aoi,
    scale: 10,  // Sentinel-2 native resolution, in metres
    maxPixels: 1e10
  }).get('groups');

// List of dictionaries {code, sum} in m2
print('areas of classes:');
print(areaPerClass);
// ---- end of Step 6, cell 6 ----

The result is a list of dictionaries in m². To read it as a table in hectares, convert it as in the lecture:

// ---- Step 6, cell 7: Convert the result into a table in hectares ----
// Convert the list of dictionaries into a table (FeatureCollection without geometry) in hectares
var areaList = ee.List(areaPerClass);
var areaTable = ee.FeatureCollection(areaList.map(function(d) {
  d = ee.Dictionary(d);
  return ee.Feature(null, {code: d.get('code'),
                           ha: ee.Number(d.get('sum')).divide(1e4).round()});
}));
print('area per class [ha]:', areaTable);
// ---- end of Step 6, cell 7 ----

Common problems
