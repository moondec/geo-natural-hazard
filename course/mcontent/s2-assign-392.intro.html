Deliverable – Milestone M2 (due before Lab 3, 30.11)

Create your own JavaScript code for GEE that calculates the area occupied by the categories of a selected index (e.g. EVI, NDWI, SAVI, NDMI). Specify any region of interest (ROI) that is not very large, e.g. a city or district, a national park. Choose your own thresholds and justify them in one or two sentences. Submit the link to the ready code (Save → Get Link) as the solution, together with a short note with the area table.

You are done when

The link opens your script in the Code Editor, it runs without errors, and the Console prints one area per class whose sum equals the ROI area.
