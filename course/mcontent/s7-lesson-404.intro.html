An Application Programming Interface (API) is a way for two or more computer programs to communicate with each other. It is a type of software interface that offers a service to other pieces of software (Wikipedia). Earth Engine has one engine and three clients: JavaScript (Code Editor), Python (ee) and R (rgee).
