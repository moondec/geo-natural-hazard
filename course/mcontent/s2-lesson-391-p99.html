Step 2: add the End-to-End Google Earth Engine course repository to your Code Editor. We use it as a cookbook during all labs, not as homework. At the end the repository is visible in your Scripts tab.

Interface overview

The Code Editor has three columns: on the left the Scripts, Docs and Assets tabs; in the middle the editor with the Run, Save and Get Link buttons; on the right the Inspector, Console and Tasks tabs. The map is below. Shared repositories appear in the Scripts tab under Reader.

Get the course materials

  1. Open the repository link. Click this link; it opens the Code Editor and adds the repository to your account.
  2. Find it in the Scripts tab. A new repository users/ujavalgandhi/End-to-End-GEE appears in the Reader section.
  3. Compare with the figure below. Your Code Editor should look like the screenshot.
  4. Browse module 1. Open 01-Earth-Engine-Basics and run one script to see how a shared script behaves (you can read and run it, but you save your own copy with Save).

Add the course script repository

All lab scripts of this course live in the teacher's repository users/marekurbaniak/GEO2, one folder per lesson (02_code_editor … 06_wildfires), each script with a header that says what to change. Click this link once; the repository appears under Reader. Open 00_README first. You can read and run every script, but save your own copy (Save as) before changing it.

You are done when

The Reader section lists users/ujavalgandhi/End-to-End-GEE and users/marekurbaniak/GEO2. Press Next to load your first image collection.

The repository is not visible

Click the Refresh repository cache button in the Scripts tab and it will show up.
