The main exercise of lab 3. You draw training samples for four land cover classes in your area, train a Random Forest on a Sentinel-2 composite, classify the area and measure the accuracy on pixels the model has not seen. At the end you have a classified map, a confusion matrix, overall accuracy and kappa – half of the report.

Supervised learning in one paragraph

Supervised classification is the result of supervised learning. A human expert classifies a piece of the data first (this is called data labelling): input parameters (predictors – the bands) and output parameters (the class) are combined into pairs. From these pairs the algorithm builds a model, i.e. it learns the patterns. Use it when you want to decide the classes yourself and you know their properties.

Labelled data: a set of training examples, where each example is a pair of input values (band values of a pixel) and an output value (its class).

Before you start

  • Reference example from the End-to-End GEE course: basic supervised classification (no imports); the exercise version is a good skeleton for your own script.
  • Chapter Module 3 – Supervised classification and Accuracy assessment of the End-to-End course.
  • Your area of interest from lab 2 (60–100 km², at least four surface types) and the median composite from COPERNICUS/S2_SR_HARMONIZED.

Step by step

  1. Build the composite. Filter COPERNICUS/S2_SR_HARMONIZED to your AOI and one season, keep scenes with little cloud, select the reflectance bands only and take the median – then composite.bandNames() is clean (no SCL, AOT, QA bands): 
    // ---- Supervised, cell 1: Build the median composite (reflectance bands only) ----
var s2 = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
  .filterBounds(aoi)
  .filterDate('2025-05-01', '2025-09-30')
  .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 20));
var composite = s2.select(['B2', 'B3', 'B4', 'B8', 'B11', 'B12']).median().clip(aoi);   // or .select('B.*')
Map.addLayer(composite, {bands: ['B4', 'B3', 'B2'], min: 0, max: 3000}, 'composite');
// ---- end of Supervised, cell 1 ----
  2. Create one layer per class. In the Code Editor open the geometry tools, add a new layer for each class (e.g. water, urban, crops, forest). In Geometry Imports change Import as from Geometry to FeatureCollection and add the property landcover with the values 0, 1, 2, 3.
  3. Draw the samples. Draw polygons (or points) inside pure patches: inside a lake, inside a forest – not on edges. Spread them over the whole area and give every class a similar total area.
  4. Merge and sample. Merge the four collections into trainingSamples and extract the band values of the pixels: 
    // ---- Supervised, cell 2: Merge the drawn classes and sample the composite ----
var trainingSamples = water.merge(urban).merge(crops).merge(forest);   // four drawn FeatureCollections
// sampleRegions reads the band values of every pixel inside the samples and keeps the landcover label
var labelledPixels = composite.sampleRegions({
  collection: trainingSamples,
  properties: ['landcover'],
  scale: 10,
  geometries: true           // keep the point geometry – needed again for k-means
});
// ---- end of Supervised, cell 2 ----
    sampleRegions drops the geometries by default; geometries: true keeps them, so the same test points can be used to check the k-means map on the next page.
  5. Split 70 / 30. Keep 30 % of the samples aside for validation – the model must never see them during training: 
    // ---- Supervised, cell 3: Split the samples into training (70 %) and test (30 %) sets ----
var withRandom = labelledPixels.randomColumn('random');
var trainSet = withRandom.filter(ee.Filter.lt('random', 0.7));
var testSet  = withRandom.filter(ee.Filter.gte('random', 0.7));
// ---- end of Supervised, cell 3 ----
  6. Train the Random Forest and classify. 50 trees is enough for a start: 
    // ---- Supervised, cell 4: Train the random forest and classify the composite ----
var classifier = ee.Classifier.smileRandomForest(50)
  .train({features: trainSet, classProperty: 'landcover',
          inputProperties: composite.bandNames()});
var classified = composite.classify(classifier);
Map.addLayer(classified, {min: 0, max: 3,
  palette: ['blue', 'gray', 'yellow', 'green']}, 'RF classification');
// ---- end of Supervised, cell 4 ----
  7. Assess the accuracy. Classify the test set and compare predicted with true classes: 
    // ---- Supervised, cell 5: Accuracy assessment on the test set ----
var testClassified = testSet.classify(classifier);              // adds the predicted 'classification' property
var confusionMatrix = testClassified.errorMatrix('landcover', 'classification');   // rows = truth, columns = predicted
print('confusion matrix', confusionMatrix);
print('overall accuracy', confusionMatrix.accuracy());
print('kappa', confusionMatrix.kappa());
print('producer accuracy', confusionMatrix.producersAccuracy());
print('consumer accuracy', confusionMatrix.consumersAccuracy());
// ---- end of Supervised, cell 5 ----
    Copy the matrix and the two numbers into your report.
  8. Export the map. Export.image.toDrive({image: classified, description: 'RF_classification', region: aoi, scale: 10, maxPixels: 1e10}) – run the task in the Tasks tab; the GeoTIFF becomes the report figure.
  9. Save the script and copy its shareable link (Get Link) – you will paste it in the report.

  • Overall accuracy = diagonal / total = 176 / 200 = 88 % in this example.
  • Producer's accuracy (recall): of the real crop pixels, how many did we find?
  • User's accuracy (precision): of the pixels we called crops, how many are crops?
  • Kappa: agreement corrected for chance (0 = random, 1 = perfect); the usual scale – 0.81–1.00 "almost perfect" – is from Landis & Koch (1977), Biometrics 33, 159–174. Report overall, producer's and user's accuracy; kappa is optional and has been criticised for map accuracy (Foody 2020, Remote Sensing of Environment 239, 111630).

Keep for the report

Classified map (exported image or screenshot with legend), confusion matrix, overall accuracy, kappa, number of training samples per class and the script link.

You are done when…

…the map shows four classes over the whole AOI, print(cm) shows a 4 × 4 matrix and the overall accuracy is above about 0.8. If it is much lower, go back to step 3 and improve the samples before changing the algorithm.

Common mistakes

  • Import as Geometry instead of FeatureCollection – then there is no landcover property and sampleRegions returns nothing useful.
  • Classes numbered 1, 2, 3, 4 in one layer and 0…3 in another – use 0…3 everywhere.
  • Samples drawn on a single date instead of the median composite – they do not represent the season.
  • Training and validation on the same pixels – the accuracy is then meaningless.
