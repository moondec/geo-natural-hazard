QGIS 1 of 4 (15 min): install the Google Earth Engine plugin, sign in with your Earth Engine account and connect it to your Cloud project. The plugin wraps the same Python API you used in Colab: after this page every Earth Engine dataset and every script of this course can be shown on the QGIS canvas next to your own layers. Screenshots on the QGIS pages come from the plugin documentation (gee-community, MIT licence).

Before you start

  • QGIS 3.44 or newer (Help → About). Plugin 0.3.x refuses older versions. The long-term release from qgis.org is fine; QGIS 4 works too. If the lab computer is older, do this page at home and use the export path of QGIS 4 today.
  • Your Google account with the registered Earth Engine Cloud project from lab 1 (milestone M1). The Code Editor must open for you in the browser.
  • Internet access without a blocking proxy (the plugin talks to earthengine.googleapis.com).

Install the plugin

  1. Open the Plugin Manager: Plugins → Manage and Install Plugins…
  2. Search and install: on the All tab type google earth engine, select Google Earth Engine (author gena, version 0.3.3 or newer) and click Install Plugin. The download includes its own copy of the Earth Engine Python library – you install nothing else.
  3. Sign-in prompt: right after the installation the plugin looks for a credentials file in your home folder (it exists if you already used the Python API or Colab on this computer). If there is none, a dialog asks you to sign in. Click OK.
  4. Choose the account in the browser tab that opens. If you have several Google accounts, pick the one with the Earth Engine project (this is the most common mistake – a private account without a registered project signs in fine and fails later). Review the permissions and click Allow; the page confirms that the credentials are saved, close the tab.

Connect the Cloud project

  1. QGIS asks for the project: the Select Earth Engine project dialog appears, because an account can have several Cloud projects.
  2. Find the project name in the Code Editor: open code.earthengine.google.com, click your account name in the top-right corner and choose Project Info.
  3. Copy the Cloud Project name shown in the window (for example ee-yourname).
  4. Paste it in QGIS and click OK. The plugin initialises with this project; a success message follows.
  5. Check the result: close the Plugin Manager. The Plugins menu now has a Google Earth Engine entry, and Processing → Toolbox lists a Google Earth Engine provider with Add EE Image, Add Image Collection, Add Feature Collection and Export → Export Image to GeoTIFF.

If it fails

"Plugin failed to initialize": open Plugins → Python Console, run import ee and ee.Authenticate(), finish the sign-in in the browser, then enable the plugin again in the Installed tab. Still failing: delete the file C:\Users\<you>\.config\earthengine\credentials (macOS/Linux: ~/.config/earthengine/credentials) and repeat. "Project … is not registered": you pasted a project that is not registered for Earth Engine – use the one from Project Info, or register it at console.cloud.google.com/earth-engine. The full list of traps is on QGIS page 4.

You are done when

The Google Earth Engine provider is in the Processing Toolbox and no error appeared after the project was set. Press Next to put your first Earth Engine layer on the canvas.
