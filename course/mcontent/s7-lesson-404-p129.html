QGIS 3 of 4 (25 min): the no-code tools. With the Processing Toolbox you add a filtered, cloud-free Sentinel-2 composite without writing a line, browse the catalogue, and – the step that matters for your deliverables – export a real GeoTIFF in the CRS and resolution you choose. The walk-through follows the plugin tutorial Downloading Images from Earth Engine, moved from Paris to your own area.

1. Add Image Collection: a Sentinel-2 median without code

  1. Zoom to your area (Poznań or the district of your homework) over the OpenStreetMap basemap. Open Processing → Toolbox, expand Google Earth Engine and double-click Add Image Collection.
  2. Collection and scene filter: paste the ID COPERNICUS/S2_SR_HARMONIZED (copied from the dataset page). In Filter by Image Properties choose CLOUDY_PIXEL_PERCENTAGE, operator <, value 30 – the scene-level filter of lesson 2.
  3. Compositing and dates: Compositing Method = Median; Filter by Dates from 01-05-2025 to 01-10-2025 (the end date is exclusive, as in the Code Editor).
  4. Extent and visualisation: in Filter by Extent click Map Canvas Extent; choose bands B4, B3, B2, min 0, max 3000; tick Clip to Extent; Run. A layer IC: COPERNICUS/S2_SR_HARMONIZED (Median) appears – streamed tiles, like the console layers of page 2.

The other no-code tools

  • Data Catalog (Plugins → Google Earth Engine → Data Catalog): a dockable panel that searches the official catalogue (and the community catalogue) by name, ID, provider or tag; Load opens the matching dialog with the asset ID filled in. Try it for FIRMS or JRC/GSW1_4.
  • Add EE Image: one image, e.g. NASA/NASADEM_HGT/001 with band elevation for a DEM under your flood map.
  • Add Feature Collection: vectors, e.g. FAO/GAUL/2025/level2 filtered to your district. Tick retain as vector layer to get a real, editable QGIS vector layer that you can export with the usual right-click Export.
  • Model Designer: these algorithms can be chained with any QGIS algorithm (raster calculator, zonal statistics) in Processing → Models – the plugin tutorial Building a Workflow shows a complete model.

2. Export Image to GeoTIFF: the file you can analyse

  1. Open the export tool: Google Earth Engine → Export → Export Image to GeoTIFF in the toolbox.
  2. Image and scale: EE Image = the median layer; Scale (meters) = 10 (native Sentinel-2). Click Select CRS.
  3. Choose a metric CRS: for Poland search 2180 (ETRF2000-PL / CS92, PUWG 1992); elsewhere the UTM zone of your area (WGS 84 / UTM zone 33N, EPSG:32633, for Poznań). The tutorial screenshot shows the UTM choice for Paris. Never export in EPSG:4326 – a 10 m pixel has no meaning in degrees.
  4. Extent and bands: Extent = Map Canvas Extent (keep it small the first time – a few kilometres); move the bands you need to the output list with >> (B4, B3, B2 for a true-colour file, or just NDVI for an index). Then Output File: a folder and a name such as s2_median_2025.tif; Run.
  5. Wait and open: the region is downloaded in tiles and merged; a few minutes for a 10 × 10 km area at 10 m. Turn the streamed layer off and drag the new .tif from the Browser panel onto the canvas – this is a normal raster now: Raster → Zonal Statistics, the raster calculator and the field calculator all work on it.

Small exports here, big exports from the Code Editor

The plugin downloads through your computer. A whole voivodeship at 10 m with six bands is gigabytes and may time out. For large areas use Export.image.toDrive in the Code Editor or ee.batch.Export in Python (the task runs on Google's side, you download one file from Drive) – QGIS page 4.

3. The same for your hazard

  1. Run a hazard script in the console: examples/qgis/02_qgis_flood_mask.py (Sentinel-1 flood mask, lab 4 method) or 03_qgis_dnbr_classes.py (dNBR classes, lab 6 method). Set the AOI and dates to your event; the console prints the hectares.
  2. Export the result layer with Export Image to GeoTIFF (scale 10 or 20, EPSG:2180, canvas extent). Class rasters come out as integers – exactly what the map on page 4 needs.
  3. Compare with the GeoTIFF you exported from the Code Editor in lab 4 or 6: load both, use the identify tool or Raster calculator ("a@1" - "b@1"). The extents should be similar; where they differ, name the reason (masks, speckle filter, threshold).

You are done when

A Sentinel-2 median built in the toolbox is on the canvas, an exported GeoTIFF in EPSG:2180 opens from the Browser panel, and the flood or burn-severity layer of your event is exported too. Press Next to turn it into a finished map.
