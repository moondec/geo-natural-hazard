The second exercise of lab 3. You let k-means group the pixels of the same composite into four clusters without any training data, then you name the clusters and compute a confusion matrix for them too. At the end you have a second map and a second accuracy table, so the two classifiers can be compared fairly.

Unsupervised learning in one paragraph

Unsupervised classification is used when the expert has no knowledge of the classes in the data and no patterns that could be used to label them. The algorithm finds groups of pixels that are similar in all bands and can help to understand the processes and relationships hidden in the data. Be careful: the computer finds spectral groups, not land cover classes, and it can find patterns without any cause-and-effect relationship. Sunlit and shaded forest may become two clusters, wheat and grass one – it is you who must look at the map and name the clusters afterwards.

Before you start

  • Reference example from the End-to-End course: unsupervised classification; another example written for Sentinel-2.
  • The same AOI and the same composite as on the previous page – otherwise the comparison is unfair.

Step by step

  1. Sample the composite. k-means needs a table of pixels, not polygons: 
    var sample = composite.sample({region: aoi, scale: 10, numPixels: 5000});
  2. Train the clusterer with k = 4 – the same number as your supervised classes – and cluster the image: 
    var clusterer = ee.Clusterer.wekaKMeans(4).train(sample);
var clusters = composite.cluster(clusterer);
Map.addLayer(clusters.randomVisualizer(), {}, 'k-means clusters');
  3. Name the clusters. Use the Inspector and the true-colour layer to decide which cluster is water, urban, crops, forest. Write the mapping down.
  4. Relabel clusters to your classes so that the cluster ids match the landcover codes 0…3 of the supervised exercise: 
    // example: cluster 2 → water (0), 0 → urban (1), 3 → crops (2), 1 → forest (3)
var kmeansClass = clusters.remap([2, 0, 3, 1], [0, 1, 2, 3]).rename('classification');
Map.addLayer(kmeansClass, {min: 0, max: 3,
  palette: ['blue', 'gray', 'yellow', 'green']}, 'k-means relabelled');
  5. Compute the confusion matrix with the same test set as for Random Forest: 
    // testSet keeps its point geometries (geometries: true on the previous page)
var testK = kmeansClass.sampleRegions({
  collection: testSet, properties: ['landcover'], scale: 10});
var cmK = testK.errorMatrix('landcover', 'classification');
print('k-means confusion matrix', cmK);
print('k-means overall accuracy', cmK.accuracy());
print('k-means kappa', cmK.kappa());
  6. Try other k. Repeat with k = 6 and k = 8 and look how the clusters split – this is the argument for the number of classes in your report.
  7. Export and save. Export the relabelled map to Drive (scale 10) and copy the script link.

You are done when…

…both maps use the same legend (0…3) and you can state which classifier has the higher overall accuracy and kappa – and why.

Common mistakes

Comparing cluster numbers directly with landcover codes without remap – the accuracy is then close to zero even for a good clustering. Using a different composite or AOI than for Random Forest. An empty testK: the first sampleRegions on the previous page was run without geometries: true, so the test features have no geometry – add it (or sample once from composite.addBands(kmeansClass)) and run again.
