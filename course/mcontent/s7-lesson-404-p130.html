QGIS 2 of 4 (20 min): your first Earth Engine layer on the QGIS canvas from the Python Console. The code is the Python you wrote in Colab; only the map object changes – from ee_plugin import Map instead of geemap. At the end you have the NDVI median of lesson 2 as a live layer over OpenStreetMap and you can read pixel values with the plugin's identify tool.

1. Open the console and its editor

  1. Add a basemap: in the Browser panel open XYZ Tiles and drag OpenStreetMap onto the canvas. Zoom to Poznań (locator bar bottom left: type > Poznań).
  2. Open the console: Plugins → Python Console. A panel appears at the bottom of QGIS.
  3. Show the editor: click the Show Editor button (notepad icon) in the console toolbar. The editor on the right lets you paste a whole script and run it with the Run Script button (green arrow) – the console line on the left is for single commands.
  4. Test the connection: paste the two lines below in the editor and run them. No error means the plugin is installed and signed in. An error sends you back to QGIS page 1. 
    import ee
from ee_plugin import Map

2. The NDVI median as a layer

  1. Paste and run the script below (also in the course repository: examples/qgis/01_qgis_console_ndvi.py). Everything before Map.addLayer runs on the Earth Engine servers, exactly as in the Code Editor and in Colab: 
    import ee
from ee_plugin import Map            # the plugin's Map replaces geemap.Map

aoi = ee.Geometry.Point(16.93, 52.41).buffer(5000)          # change to your area
s2 = (ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
        .filterBounds(aoi).filterDate('2025-05-01', '2025-09-30')
        .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 30)))
ndvi = s2.map(lambda i: i.normalizedDifference(['B8', 'B4']).rename('NDVI')).median()
print('Scenes:', s2.size().getInfo())                       # printed in the console

Map.addLayer(s2.median().clip(aoi), {'bands': ['B4', 'B3', 'B2'], 'min': 0, 'max': 3000},
             'S2 median true colour', False)
Map.addLayer(ndvi.clip(aoi), {'min': -0.2, 'max': 0.8,
             'palette': ['blue', 'white', 'yellow', 'green', 'darkgreen']}, 'NDVI median 2025')
Map.centerObject(aoi, 11)
  2. What you got: two layers in the Layers panel. They are streamed from Earth Engine as tiles (a WMS-like data provider): zoom and pan recompute them on the fly, you can change the order and the opacity, overlay your own vectors, save them in the project. You cannot edit them, run zonal statistics on them or measure them – for that you export (QGIS page 3 and 4). Turn the true-colour layer on and off to see the NDVI over the real image.
  3. The Map functions that the plugin understands, named like in the Code Editor:
    FunctionWhat it does
    Map.addLayer(eeObject, visParams, name, shown, opacity)adds an image, image collection (mosaicked) or feature collection as a layer
    Map.centerObject(object, zoom) / Map.setCenter(lon, lat, zoom)moves the canvas
    Map.getBounds(asGeoJSON), Map.getCenter(), Map.getZoom(), Map.getScale()read the current view – useful to build an ee.Geometry from the canvas extent
    ui.Chart, Export.* and print() of the Code Editor do not exist here: print with .getInfo(), export with the Processing tool (page 3) or ee.batch.Export.

3. Read values: the identify tool

  1. Select the layer(s) you want to query in the Layers panel (highlighted in blue; several Earth Engine layers can be selected at once).
  2. Click the map with the Identify Earth Engine Pixel or Region tool (plugin toolbar or Plugins → Google Earth Engine). A click returns the band values at that point; a dragged box returns the mean of the box. Check a field, a forest and a lake – the NDVI values must match the classes you chose in lesson 2.
  3. Your own data: drag any shapefile or GeoPackage onto the canvas (the district border from lab 2, the EMS perimeter from lab 4) – it draws over the Earth Engine layer, reprojected on the fly.

You are done when

The NDVI layer shows over OpenStreetMap, the console printed the number of scenes, and the identify tool returns NDVI values for three points. Press Next for the no-code tools and the export to GeoTIFF.
