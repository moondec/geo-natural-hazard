Step 4: the JavaScript basics of every Earth Engine script – load a collection, define an area of interest, filter by date, clouds and location. Type the code line by line into a new script (do not paste the whole block); at the end the Console prints the number of scenes.

1. Image collections

A collection can be added to the script by (1) the Import button on the dataset page or (2) as a variable in the code:

// (1) Import: the collection appears in the Imports panel at the top of the script
var s2 = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED');

// (2) Variable in the code
// This is a comment (description or note)
// mark text and hit "ctrl+/" or "cmd+/" on Mac
/*
 This is also a comment (description or note)
*/
var s2 = ee.ImageCollection("COPERNICUS/S2_SR_HARMONIZED");

2. Specific location and zoom level

// polygon
var aoi = ee.Geometry.Polygon([16.79,52.98,16.5,52.98,16.5,52.4,16.79,52.4]);
Map.centerObject(aoi, 9);

// point
var poi = ee.Geometry.Point(16.79,52.9);
var aoi = poi.buffer(100); // 100 m around poi
Map.centerObject(aoi, 16);

3. Filtering image collections

var s2Filtered = s2.filterDate('2025-05-01', '2025-09-30')      // filter by date: the 2025 growing season (end date is exclusive)
               // pre-filter to get less cloudy granules (Sentinel-2)
               .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 35))
               .filter(ee.Filter.bounds(aoi));
               // .filterBounds(aoi);   // or use the short-cut for the line above

// check the number of images after filtering
print(s2Filtered.size());

You are done when

The Console prints a number (not an error) after print(s2Filtered.size()), and the map is centred on your region. Press Next to remove the clouds before any index.

Common problems

s2Filtered.size() prints 0: your filters are too strict – widen the dates, raise the cloud threshold or check that aoi lies where you think. A missing semicolon is not an error in JavaScript, but a missing bracket is: read the red line number in the Console.
