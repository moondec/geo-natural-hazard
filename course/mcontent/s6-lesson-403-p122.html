Lab 6 (21.12, 3 h): you run the UN-SPIDER burn severity script on your fire (the one you found in Copernicus Browser last week), classify dNBR with the USGS thresholds, compare the result with EFFIS and export the map. At the end you submit the burn severity map and report – milestone M6.

Before you start

  • The script: code.earthengine.google.com/13813e68fd5bb31c21ccdfa515f6165e (based on the UN-SPIDER recommended practice).
  • Your fire: start and end dates from FIRMS hotspots, cloud-free pre- and post-fire Sentinel-2 dates from Copernicus Browser, the perimeter from EFFIS (Europe) or Copernicus EMS.
  • Your own area of interest: comment out line 19 of the script and assign a new geometry – draw it with the editor tools or upload a feature collection (shapefile, GeoJSON) as an asset.

Steps

  1. Set the dates. Replace the four dates in the SET TIME FRAME block below with your pre-fire and post-fire windows. Each window must be long enough for Sentinel-2 to acquire a cloud-free image (revisit 5 days); if an ImageCollection in the Console has 0 elements, widen the window. 
    //*******************************************************************************************
//                                     SET TIME FRAME
// Set start and end dates of a period BEFORE the fire. Make sure it is long enough for
// Sentinel-2 to acquire an image (repetition rate = 5 days). Adjust these parameters, if
// your ImageCollections (see Console) do not contain any elements.

var prefire_start = '2016-12-20';
var prefire_end = '2017-01-18';

// Now set the same parameters for AFTER the fire.
var postfire_start = '2017-02-20';
var postfire_end = '2017-03-28';

//*******************************************************************************************
  2. Set the area (geometry) and run the script. Check in the Console how many pre and post images were found.
  3. Inspect the layers NBR pre, NBR post and dNBR with the Inspector: click unburned forest, an agricultural field and the fire core and note the values.
  4. Classify dNBR with the USGS thresholds from page 3 (−250, −100, 100, 270, 440, 660 on the × 1000 scale), add a legend and compute the area per class in hectares (the grouped reducer from lab 2).
  5. Compare the perimeter with EFFIS or EMS: where do they disagree and why (clouds, phenology, agricultural fields)?
  6. Optional: an NDVI or NBR time series chart (ui.Chart.image.series) over the perimeter for two years after the fire – vegetation recovery.
  7. Export the severity map as GeoTIFF (Export.image.toDrive, scale 20 m, your region) and write the report with the checklist from page 3.

Deliverable – milestone M6 (21.12)

Burn severity map + report: data and dates (pre, post, FIRMS timeline), method, thresholds, area per class in hectares, comparison with the EFFIS/EMS perimeter, limitations, and the link to your saved script.

You are done when

the unburned class covers the area outside the perimeter, the dNBR histogram over the perimeter has its unburned peak near 0, and the sum of the class areas equals your AOI area.

Common problems

High severity everywhere – a cloud in the pre composite; mask per pixel and check the true-colour view. Low severity outside the perimeter – pre and post differ in season (phenology); choose dates closer together. Empty collection – dates or geometry wrong, or CLOUDY_PIXEL_PERCENTAGE filter too strict.
