We can also run R code in python kernel:
```
%load_ext rpy2.ipython
```

Then use %%R to execute cell magic. Use this if you want all syntax in a cell to be executed in R. Note that this must be placed at the beginning of the cell.
```
%%R
a<-seq(1,10)
set.seed(1313) #for reproductive results
b<-runif(10)*a
#plot(b~a)
df<-data.frame('x'=a,'y'=b)
ggplot(df,aes(x,y))+theme_bw() + geom_point() + geom_smooth(method='lm')
```

Use %R to execute line magic. Use this if you want a single line in a cell to be executed in R.

Here is how you could use this line magic to copy R variable to Python:

```
# py_df - python variable
# df - R variable
py_df=%R df
print(py_df)
```
