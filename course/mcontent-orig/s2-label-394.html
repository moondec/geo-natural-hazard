Administrative borders you can download from GADM or simplemaps.com website.


And here is a piece of code for GEE (ee.FeatureCollection())


 var extent_pl = ee.FeatureCollection("FAO/GAUL/2015/level0")
                   .filter(ee.Filter.eq("ADM0_NAME", "Poland")); //filter for entry that equals the UN country name "Poland"

or an example from End-to-End course:

```
var admin2 = ee.FeatureCollection("FAO/GAUL_SIMPLIFIED_500m/2015/level2");
    var karnataka = admin2.filter(ee.Filter.eq("ADM1_NAME", "Karnataka"));
    var visParams = {"color": "red"};

Map.addLayer(karnataka, visParams, "Karnataka Districts");
```

Note

Number 0 and 1 in variables: ADM0_NAME or ADM1_NAME, refers to level of the administrative delimitation.
