In this page we will try calculate areas inside "roi" covered by life, green vegetation

First import collection and create "roi"

```

// Function to calculate and add an NDVI band
var addNDVI = function(image) {
return image.addBands(image.normalizedDifference(['B8', 'B4']).rename('NDVI'));
};

// Add NDVI band to image collection
var S2a = S2a.map(addNDVI);

var NDVI = S2a.select(['NDVI']);
var NDVImed = NDVI.median();

```

Manual classification. We create separate layer for each class, and than a specific values are assigned to particular class.

  • "water" = -1
  • "rocks" = 2
  • "shrub" = 3
  • "vegetation" = 4

This solution is not efficient - just for exercise - do not use in real calculations
```

// Manual classification combining bands and defining values in GEE
var water = NDVImed.lte(-0.1).rename('Water').multiply(-1); // water is '-1'
// print(water)
var rock = NDVImed.gt(-0.1).and(NDVImed.lte(0.3)).rename('Rock').multiply(2);  // rocks is '2'
// print(rock)
var shrub = NDVImed.gt(0.3).and(NDVImed.lte(0.4)).rename('Shrub').multiply(3);
// print(shrub)
var vegetation = NDVImed.gt(0.4).rename('Green').multiply(4);
// print(vegetation)
```

Now we can add new bands to image

```
var classimage = NDVImed.addBands(water)
var classimage = classimage.addBands(rock)
var classimage = classimage.addBands(shrub)
var classimage = classimage.addBands(vegetation)
```

and finally compute area (try change "Green" to "Rock" or "Shrub")

```
// Lets compute the Green area
var classareas = ee.Image.pixelArea().addBands(classimage.select('Green'))
  .reduceRegion({
    reducer: ee.Reducer.sum().group({
      groupField: 1,
      groupName: 'code',
    }),
    geometry: roi,
    scale: 1,  // sample the geometry at 1m intervals
    maxPixels: 3e10
  }).get('groups');
 
  // Print the list of dictionaries.
print(classareas);
```
