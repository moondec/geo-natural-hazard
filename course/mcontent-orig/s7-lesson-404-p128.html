`rgee` library is a kind of "translator" between R and python API for GEE.

1. Why `rgee` instead of code editor (Javascript)?

A short comparison based on Tyler Erickson presentation.

Code Editor R
Easy to get started Easy to share code between scripts.
Trivial to share scripts Easier transition to a web application (Shiny).
Built in authentication An I/O API more friendly with R users.
Limited input/output functionality Many, many plotting options
Integration with other JS libraries is not possible Some assembly (& maintenance) required!.

2. Installation

rgee depends on reticulate, R6 and processx. To install rgee run:
```
install.packages("rgee")
```
R will download quite a lot of software. After installation source library:
```
library(rgee)
```

rgee has two types of dependencies: strict dependencies that must be present before rgee initialization (i.e. ee_Initialize()) and the credentials dependencies that unlock all rgee I/0 functionality with Google Drive (GD) and Google Cloud Storage (GCS).

If the strict dependencies are not installed, rgee just will not work. These dependencies are:

  • Google account with Earth Engine activated

  • Python >= v3.5

  • EarthEngine Python API (Python package)

The credentials dependencies are only needed to move data from Google Drive and Google Cloud Storage to your local environment. These dependencies are not mandatory. However, they will help you to create a seamless connection between R and Earth Engine. These dependencies are:

  • Google Cloud Storage credential

  • Google Drive credential

The activation of an Earth Engine account depends on each user, check the official website of Google Earth Engine for more details.
You can check strict dependencies:
```
ee_check()
```

If you have already python on your system you can use them. But if not or you wish use specific isolated python environment and you have enough space (~200 MB) at hard drive, RUN:
```
library(rgee)
ee_install(py_env = "rgee") # It is just necessary once!
```

3. Authentication

This part is not mentioned in the official manual. You have to download gcloud (SDK)

Please follow the manual. It can take a few minutes

Download 

```
.zip
```
 file:

  1. Download google-cloud-sdk.zip and extract its contents. (Right click on the downloaded file and select Extract All.)

  2. Launch the 

    ```
    google-cloud-sdk\install.bat
    ```
     script and follow the installation prompts.

  3. When the installation finishes, restart the command prompt (

    ```
    cmd.exe
    ```
    ).

  4. Run 

    ```
    gcloud init
    ```
    :

    ```
    C:\> gcloud init
    ```

    Now check strict dependencies again
    ```
    ee_check()
    ```
