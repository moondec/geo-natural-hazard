1. Image Collections

The collection can be added to working space (indexArea) by the (1) import or as (2) variable:

(1)
```
var S2har = ee.ImageCollection('COPERNICUS/S2_HARMONIZED');

```

(2)
```

// This is comment (description or note)
// mark text and hit "ctr+/" or "cmd+/" on Mac
/*
This is also comment (description or note)
*/

```

2. Specific location and zoom level

```

// poligon
var aoi = ee.Geometry.Polygon([16.79,52.98,16.5,52.98,16.5,52.4,16.79,52.4])
Map.centerObject(aoi, 9);

```

```

// point
var poi = ee.Geometry.Point(6.79,52.9)
var roi = poi.buffer(100); // 100 m around poi
Map.centerObject(roi, 16);

```

3. Filtering Image Collections

```
var S2a = S2har.filterDate('2019-05-01', '2019-09-30')    // filter according date
            // Pre-filter to get less cloudy granules.    (Sentinel-2)
            .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 35))  
            .filter(ee.Filter.bounds(roi));
            // .filterBounds(roi); // or use short-cut for line above

```


```

// check number of images after filtration
print(S2a.size())

```
