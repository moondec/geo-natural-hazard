1. Supervised Classification made by use of computer algorithms is a result of Supervised learning. 

The process requires a human expert who will perform classification on a piece of data (The process sometimes is called "data labelling*"). It involves defining input parameters (predictors) and output parameters (results) and combining them into pairs (groups and pairs). In this way, it will build a model, i.e. teach the computer patterns.

This type of classification is used when we want to decide about assigned classes and know their properties.

* Labelled data: Data consisting of a set of training examples, where each example is a pair consisting of input and output values.
